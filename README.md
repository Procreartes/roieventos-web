# Roieventos.es

Web corporativa de **Roieventos**, marca de **Naroe Consulting SL**.

Consultoría especializada en **PreROI, ROI y Estudios de Impacto Económico** para festivales, conciertos y eventos culturales.

## Stack

Sitio estático single-file (HTML + CSS + JS vanilla). Sin build, sin frameworks.

- Tipografías: Playfair Display, Cormorant Garamond, Inter (Google Fonts)
- Iconos: Font Awesome 6.5.1 (CDN)
- Estilo: editorial revista de negocios
- Paleta: burdeos `#722F37` + dorado `#C9A961` + crema `#FAF6EE`

## Estructura

```
roieventos/
├── index.html      # Web completa
├── README.md
└── .gitignore
```

## Deploy

Deploy automático en Coolify (Hetzner) como **static site** desde este repositorio público.
